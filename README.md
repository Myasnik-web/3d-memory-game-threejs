## 🚀 Features

* **3D Interactive Cores:** Multi-layered Sci-Fi icosahedrons featuring metallic inner cores and wireframe outer meshes.
* **Procedural Particle Effects:** Dynamic 3D particle explosions triggered on interactions and correct sequence inputs.
* **Cyberpunk HUD & Environment:** Tron-inspired animated 3D grid floor, CRT scanline overlay, and glow/neon accents.
* **Procedural Audio Synthesizer:** Built-in Web Audio API tone generator — no external audio files required.
* **3 Tactical Game Modes:**
  * **NORMAL:** Replicate the sequence step-by-step.
  * **REVERSE:** Memorize the sequence and replicate it in reverse order.
  * **HYPER:** Fast-paced mode with accelerated pattern flashing.
* **Persistence:** High scores are saved locally via `LocalStorage`.

---

## 🛠️ Tech Stack

* **3D Engine:** [Three.js](https://threejs.org/) (WebGL Render loop, Raycasting, Dynamic Lighting, Fog)
* **Audio:** Web Audio API (OscillatorNode & GainNode)
* **Styling:** CSS3 (Flexbox, Glassmorphism, CSS Custom Properties, Google Fonts Orbitron & Share Tech Mono)
* **Markup:** HTML5
